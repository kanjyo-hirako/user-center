# 用户管理中心 (User Center)

- 一个基于 Vue 3 + Spring Boot 的全栈用户管理系统，实现了用户注册、登录、头像上传裁剪、管理员用户管理等核心功能。

- 前端文件放在了user-center-frontend-vue文件夹中，后端文件放在了user-center-backend文件夹中的user-center-backend-master文件夹中

- Log.md是日志文件

## 核心功能

### 前端 (Vue 3 + Ant Design Vue)

- **首页粒子动画**：基于 Canvas 的交互式粒子动画，展示"欢迎来到用户中心"字样，鼠标悬停时粒子散开后回归
- **用户注册**：表单包含账号、密码、确认密码、用户名四项，支持密码一致性校验、用户名特殊字符检测、最小长度限制
- **用户登录**：基于 Cookie/Session 的认证方式，登录成功后自动跳转至管理页面，401 错误自动重定向至登录页
- **会话保持**：应用启动时自动获取当前登录用户状态，刷新页面不丢失登录信息
- **路由守卫**：未登录用户访问管理页面自动拦截并提示登录；已登录用户访问登录/注册页自动跳转首页
- **用户管理（管理员）**：以表格形式展示所有用户信息（用户名、账号、头像、创建时间、角色），支持按用户名搜索
- **头像上传与裁剪**：支持图片上传（限 2MB），上传后弹出裁剪模态框，可拖拽定位、滚轮/滑块缩放（1x~5x）、调整裁剪框大小，确认后裁剪并重新上传
- **角色权限控制**：仅管理员账号可删除用户，管理员角色以绿色标签标识，普通用户以蓝色标签标识

### 后端 (Spring Boot + MyBatis-Plus)

- **用户注册**：校验账号长度（≥4）、密码长度（≥8）、特殊字符过滤、账号/用户名唯一性检查，密码经 MD5 加盐（"yupi"）哈希存储
- **用户登录/登出**：登录成功后将脱敏用户信息存入 HttpSession（有效期 24 小时），登出时清除 Session
- **用户数据脱敏**：返回用户信息时自动剔除密码、逻辑删除标记等敏感字段
- **用户搜索**：按用户名模糊查询，返回匹配用户列表
- **用户删除**：仅管理员可执行，通过账号名判断权限（账号为 "admin" 即为管理员）
- **头像文件上传**：接收 multipart 文件，以 UUID 重命名存储至服务器本地目录，更新数据库中的头像 URL，并通过静态资源映射使头像可通过 URL 访问
- **统一响应格式**：所有接口返回 `{code, data, message, description}` 结构，错误码涵盖参数错误（40000）、未登录（40100）、无权限（40101）、系统错误（50000）等
- **全局异常处理**：捕获 BusinessException 和 RuntimeException，统一返回标准化错误响应

## 实现效果

| 场景             | 效果                                                             |
| ---------------- | ---------------------------------------------------------------- |
| 访问首页         | 全屏粒子动画展示欢迎文字，鼠标交互有散开回归效果                 |
| 注册             | 填写账号/密码/用户名后注册成功，自动跳转登录页                   |
| 登录             | 输入账号密码登录成功，跳转至用户管理页，右上角显示"退出登录"     |
| 未登录访问管理页 | 弹出"请先登录"提示，自动跳转至登录页，登录后可返回原页面         |
| 管理员管理用户   | 搜索用户、查看用户列表（含头像/角色标签/创建时间）、删除普通用户 |
| 上传头像         | 选择图片后弹出裁剪框，拖拽+缩放调整裁剪区域，确认后头像更新      |
| 刷新页面         | 登录状态保持，不丢失当前用户信息                                 |
